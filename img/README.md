Сюди кладемо фото NASA для екрана підсумку. Назви файлів — у `data/media.json`.
Беріть зображення з https://images.nasa.gov або https://photojournal.jpl.nasa.gov і записуйте авторство в поле `credit`.

У `items/thumb/` лежать легкі мініатюри карток (готує `npm run thumbs`). Їх теж потрібно завантажувати на GitHub.
